# Расчёт долей

Требования R-SH-01…09 в `docs/SPEC.md`. Реализация — одна чистая функция:

```python
def recalculate(offers: Sequence[OfferShare]) -> list[OfferShare]: ...
```

## Алгоритм

1. `removed` → доля 0, закрепление снято.
2. `pinned_total` = сумма закреплённых активных. Больше 100 → `ShareOverflow`.
3. `free` = незакреплённые активные в порядке добавления.
   - `free` пуст: `pinned_total` обязан быть 100 (если активные есть), иначе `ShareOverflow`.
   - `rest = 100 − pinned_total`. `rest < len(free)` → `ShareOverflow` (никто из активных не получает 0).
4. `base, extra = divmod(rest, len(free))`. Первые `extra` офферов получают `base + 1`, остальные `base`.

## Примеры

| Состав | Результат |
|--------|-----------|
| A, B, C | 34, 33, 33 |
| A, B, C, D | 25, 25, 25, 25 |
| A, B, C📌25 | 38, 37, 25 |
| A, B, C📌25, D | 25, 25, 25, 25 |
| A, B (removed), C | 50, 0, 50 |
| A📌60, B📌50 | `ShareOverflow` |
| A📌100, B | `ShareOverflow` |

## Инварианты

- сумма долей активных = 100 (или активных нет);
- закреплённые доли не изменились;
- у removed — 0;
- при отказе входные данные не изменены: функция возвращает новый список;
- одинаковый вход даёт одинаковый выход.
