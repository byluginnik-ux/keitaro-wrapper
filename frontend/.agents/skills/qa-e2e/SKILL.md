# Сквозные проверки

## Автоматические (Playwright)

- Тесты в `tests/e2e/`, по файлу на сценарий из SPEC.md: `s2-add-offer.spec.ts`.
- Фронт запускается целиком (Nuxt + BFF); вместо бэкенда — поддельный сервер GraphQL с состоянием сценария. Настоящий Keitaro не используется.
- Локаторы — по роли и тексту. Ожидания — по состоянию страницы, без `waitForTimeout`.
- Каждый сценарий проверяет числа долей и метки состояния, а не только отсутствие ошибок.
- Проверка с клавиатуры — отдельный тест: добавить оффер, закрепить долю и опубликовать без мыши.

## Ручные (chrome-devtools MCP)

Перед закрытием фичи фронта:

1. Снимки экрана: светлая и тёмная темы, ширины 360 и 1280 px.
2. Консоль без ошибок и предупреждений.
3. Сеть: браузер обращается только к `/api/*` своего источника; адреса бэкенда и ключа Keitaro в запросах и ответах нет.
4. Lighthouse: доступность не ниже 95.
5. `prefers-reduced-motion: reduce` — состояния различимы.

## Живой Keitaro

Только в F12, вручную, на кампаниях `test_bulygin_*`: создать, пройти S1–S8, сверить доли с админкой, удалить кампании.
