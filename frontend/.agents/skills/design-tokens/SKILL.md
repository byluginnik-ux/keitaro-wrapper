# Токены

Описание — `frontend/DESIGN.md`. Значения — `app/assets/styles/tokens.css`. Компоненты читают только токены.

## Правила

- В компонентах нет сырых значений цвета, шрифта и радиуса: только `var(--…)`. Нужного токена нет — сначала правка `DESIGN.md` и `tokens.css`, потом компонент.
- Две роли цвета не смешиваются: акцент — действие, выбор, изменение; риск — отказ, ошибка, removed.
- Каждая пара цветов задаётся для обеих тем через `light-dark()`; `color-scheme` следует системе, переключатель ставит `data-mode` на `<html>`.
- Числа — `--mono` и `font-variant-numeric: tabular-nums`: доли в столбце не прыгают.
- Размеры шрифта в `rem`, отступы кратны 8 px.
- Радиусы: пилюля — кнопки, чипы, метки; `--r-box` — поля и строки; `--r-panel` — панели.

## Проверка

- Контраст текста и границ элементов управления — не ниже AA в обеих темах. Новую пару проверять числом, а не на глаз.
- Вид показывать снимком экрана в обеих темах (chrome-devtools), а не описанием.
- Ширины: 360 px, 1280 px, сверхширокий экран; горизонтальной прокрутки нет.

## Движение

Только смена цвета 120 мс. При `prefers-reduced-motion: reduce` переходы выключены, а смена состояния остаётся видимой.

## Стили в компонентах

`<style scoped>`, классы по смыслу (`.offer-row`, `.share-bar`), без утилитарных классов и без `!important`. Общие примитивы (кнопка, поле, метка) — отдельные компоненты, а не копии стилей.
