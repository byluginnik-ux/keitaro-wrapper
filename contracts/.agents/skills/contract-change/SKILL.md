# Изменение контракта

Единственная точка правки типов, общих для бэкенда и фронта, — `contracts/schema.graphql`.

## Порядок

1. **Схема.** Править `schema.graphql`. У каждого типа и неочевидного поля — описание (`"""…"""`): оно попадает в оба набора типов.
2. **Версия.** `VERSION` по semver и запись в `CHANGELOG.md`:
   | Изменение | Версия |
   |-----------|--------|
   | убрано или переименовано поле, тип, аргумент; поле стало необязательным в ответе или обязательным во входе | мажорная |
   | добавлены тип, поле, запрос, мутация, значение enum, вариант union | минорная |
   | описания | патч |
3. **Генерация.** `scripts/generate.sh` — обновит `keitaro_contracts/types.py`, `ts/generated.ts`, версию в `package.json`.
4. **Проверка.** `scripts/check.sh`.
5. **Коммит контракта:** `feat(contracts): add stream result union` (все файлы пакета одним коммитом).
6. **Части.** После этого проверки частей покажут, что дописать:
   - бэкенд: `uv run pyright` и тест соответствия схемы (`backend/tests/graphql/test_contract_conformance.py`) — красные, пока резолвер не приведён к контракту;
   - фронт: `corepack pnpm typecheck` — ошибки в местах, где используется изменённый тип.
   Правки частей — отдельными коммитами `feat(backend/…)`, `feat(frontend/…)`.

## Правила схемы

- Предметные ошибки — типы в union результата мутации, у каждого поле `message: String!`. Строковые коды ошибок не заводить.
- Мутация возвращает union. Несколько аргументов собираются в один `input`-тип; единственный идентификатор передаётся аргументом (`cancelDraft(streamId: ID!)`).
- Списки и их элементы — non-null (`[Offer!]!`), если пустое значение не несёт смысла.
- Наш идентификатор — `ID`; идентификатор Keitaro — `Int` в поле `keitaroId`. В справочниках Keitaro (`Offer`, `Domain`) `id: Int` — это и есть ID Keitaro.
- Enum — в верхнем регистре (`ACTIVE`, `REMOVED`). Описаний (`"""…"""`) у enum, его значений и у union не писать: `strawberry schema-codegen` их теряет, и тест пакета падает; смысл — комментарием `#` над определением.
- Добавление значения в enum или варианта в union ломает исчерпывающий `switch` у потребителя — это ожидаемо и считается минорным изменением, о нём пишется в CHANGELOG.

## Чего не делать

- Не править сгенерированные файлы и не «чинить» типы в части в обход контракта.
- Не описывать в схеме то, что нужно только одной части (модель экрана BFF, доменные модели бэкенда).
- Не публиковать пакеты в реестры без прямого указания человека.

## Сгенерированные типы Python

Генератор — `strawberry schema-codegen`; `scripts/generate.py` убирает из вывода `Query`, `Mutation` и объект `schema`. Тест `tests/test_contract.py` строит схему из сгенерированных типов и сверяет каждый тип со схемой — ручная правка `types.py` его роняет.
