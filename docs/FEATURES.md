# Список фич

Порядок работ. Требования — в [SPEC.md](SPEC.md).

Правила:

- одна фича — одна ветка `feat/Fxx-краткое-имя` от `main`;
- внутри ветки сначала коммит `test(...)` с падающим тестом, затем `feat(...)` с реализацией, при нужде `refactor(...)`;
- в `main` ветка попадает через rebase и fast-forward;
- фича закрыта, когда её тесты зелёные, линтеры чистые и строка в матрице SPEC.md заполнена.
